# textareacontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"textarea"` | 是 | 指定为多行文本输入框 |
| `maxRows` | `number` | 否 | 最大行数 |
| `minRows` | `number` | 否 | 最小行数 |
| `readOnly` | `boolean` | 否 | 是否只读 |
| `borderMode` | `"none" \| "full" \| "half"` | 否 | 边框模式，全边框，还是半边框，或者没边框。 |
| `maxLength` | `number` | 否 | 限制文字个数 |
| `showCounter` | `boolean` | 否 | 是否显示计数 |
| `clearable` | `boolean` | 否 | 输入内容是否可清除 |
| `resetValue` | `string` | 否 | 重置值 |
