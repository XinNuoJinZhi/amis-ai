# expandable

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `string` | 是 | 对应渲染器类型 |
| `keyField` | `string` | 是 | 对应数据源的key值 |
| `expandableOn` | `string` | 是 | 行是否可展开表达式 |
| `expandedRowClassNameExpr` | `string` | 是 | 展开行自定义样式表达式 |
| `expandedRowKeys` | `(string \| number)[]` | 是 | 已展开的key值 |
| `expandedRowKeysExpr` | `string` | 是 | 已展开的key值表达式 |
