# numbercontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"input-number"` | 是 |  |
| `max` | `number` | 否 | 最大值 |
| `min` | `number` | 否 | 最小值 |
| `step` | `number` | 否 | 步长 |
| `precision` | `number` | 否 | 精度 |
| `showSteps` | `boolean` | 否 | 是否显示上下点击按钮 |
| `borderMode` | `"none" \| "full" \| "half"` | 否 | 边框模式，全边框，还是半边框，或者没边框。 |
| `prefix` | `string` | 否 | 前缀 |
| `suffix` | `string` | 否 | 后缀 |
| `unitOptions` | `any` | 否 | 单位列表 |
| `big` | `boolean` | 否 | 是否是大数，如果是的话输入输出都将是字符串 |
| `kilobitSeparator` | `boolean` | 否 | 是否千分分隔 |
| `readOnly` | `boolean` | 否 | 只读 |
| `keyboard` | `boolean` | 否 | 是否启用键盘行为 |
| `displayMode` | `"base" \| "enhance"` | 否 | 输入框为基础输入框还是加强输入框 |
