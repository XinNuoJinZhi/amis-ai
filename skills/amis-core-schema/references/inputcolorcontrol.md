# inputcolorcontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"input-color"` | 是 | 指定为颜色选择框 |
| `clearable` | `boolean` | 否 | 是否显示清除按钮 |
| `format` | `"hex" \| "rgb" \| "rgba" \| "hsl"` | 否 | 颜色格式 |
| `closeOnSelect` | `boolean` | 否 | 选中颜色后是否关闭弹出层。 |
| `presetColors` | `PresetColor[]` | 否 | 预设颜色，用户可以直接从预设中选。 |
| `allowCustomColor` | `boolean` | 否 | 是否允许用户输入颜色。 |
