# breadcrumb

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"breadcrumb"` | 是 | 指定为面包屑显示控件 |
| `itemClassName` | `string` | 否 | 面包项类名 |
| `separator` | `string` | 否 | 分隔符 |
| `separatorClassName` | `string` | 否 | 分隔符类名 |
| `dropdownClassName` | `string` | 否 | 下拉菜单类名 |
| `dropdownItemClassName` | `string` | 否 | 下拉菜单项类名 |
| `items` | `BreadcrumbItemSchema[]` | 是 | 列表 |
| `labelMaxLength` | `number` | 否 | labelMaxLength |
| `tooltipPosition` | `TooltipPositionType` | 否 | 浮窗提示位置 |
