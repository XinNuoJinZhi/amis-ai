# hbox

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"hbox"` | 是 | 指定为each展示类型 |
| `columns` | `HBoxColumnObject[]` | 是 |  |
| `subFormMode` | `"horizontal" \| "normal" \| "inline"` | 否 | 配置子表单项默认的展示方式。 |
| `subFormHorizontal` | `FormHorizontal` | 否 | 如果是水平排版，这个属性可以细化水平排版的左右宽度占比。 |
| `gap` | `"xs" \| "sm" \| "md" \| "lg" \| "none" \| "base"` | 否 | 水平间距 |
| `valign` | `"top" \| "bottom" \| "between" \| "middle"` | 否 | 垂直对齐方式 |
| `align` | `"right" \| "left" \| "between" \| "center"` | 否 | 水平对齐方式 |
