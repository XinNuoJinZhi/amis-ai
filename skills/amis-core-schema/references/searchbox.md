# searchbox

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"search-box"` | 是 | 指定为搜索框。<br><br>文档：https://aisuda.bce.baidu.com/amis/zh-CN/components/search-box |
| `className` | `SchemaClassName` | 否 | 外层 css 类名 |
| `name` | `string` | 否 | 关键字名字。 |
| `placeholder` | `string` | 否 | 占位符 |
| `mini` | `boolean` | 否 | 是否为 Mini 样式。 |
| `enhance` | `boolean` | 否 | 是否为加强样式 |
| `clearable` | `boolean` | 否 | 是否可清除 |
| `searchImediately` | `boolean` | 否 | 是否立马搜索。 |
| `clearAndSubmit` | `boolean` | 否 | 是否开启清空内容后立即重新搜索 |
| `loading` | `boolean` | 否 | 是否处于加载状态 |
