# inputcitycontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"input-city"` | 是 | 指定为城市选择框。 |
| `extractValue` | `boolean` | 否 | 开启后只会存城市的 code 信息 |
| `joinValues` | `boolean` | 否 | 是否将各个信息拼接成字符串。 |
| `delimiter` | `string` | 否 | 拼接的符号是啥？ |
| `allowCity` | `boolean` | 否 | 允许选择城市？ |
| `allowDistrict` | `boolean` | 否 | 允许选择地区？ |
| `allowStreet` | `boolean` | 否 | 允许选择街道？ |
| `searchable` | `boolean` | 否 | 是否显示搜索框 |
| `itemClassName` | `string` | 否 | 下拉框className |
