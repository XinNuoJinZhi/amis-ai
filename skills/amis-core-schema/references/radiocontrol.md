# radiocontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"radio"` | 是 | 指定为多行文本输入框 |
| `trueValue` | `string \| number \| boolean` | 否 | 勾选值 |
| `falseValue` | `string \| number \| boolean` | 否 | 未勾选值 |
| `option` | `string` | 否 | 选项说明 |
| `badge` | `BadgeObject` | 否 | 角标 |
| `partial` | `boolean` | 否 |  |
| `optionType` | `"button" \| "default"` | 否 |  |
