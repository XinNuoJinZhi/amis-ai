# quartercontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"input-quarter"` | 是 | 指定为月份时间选择控件 |
| `format` | `string` | 否 | 月份存储格式 |
| `inputFormat` | `string` | 否 | 月份展示格式 |
| `valueFormat` | `string` | 否 | 替代format |
| `displayFormat` | `string` | 否 | 日期展示格式(新：替代inputFormat) |
