# switchcontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"switch"` | 是 | 指定为多行文本输入框 |
| `trueValue` | `string \| number \| boolean` | 否 | 勾选值 |
| `falseValue` | `string \| number \| boolean` | 否 | 未勾选值 |
| `option` | `string` | 否 | 选项说明 |
| `onText` | `SchemaCollection` | 否 | 开启时显示的内容 |
| `offText` | `SchemaCollection` | 否 | 关闭时显示的内容 |
| `size` | `"sm" \| "md"` | 否 | 开关尺寸 |
| `loading` | `boolean` | 否 | 是否处于加载状态 |
