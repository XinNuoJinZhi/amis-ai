# grid

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"grid"` | 是 | 指定为 Grid 格子布局渲染器。 |
| `columns` | `GridColumnObject[]` | 是 | 列集合 |
| `gap` | `"xs" \| "sm" \| "md" \| "lg" \| "none" \| "base"` | 否 | 水平间距 |
| `valign` | `"top" \| "bottom" \| "between" \| "middle"` | 否 | 垂直对齐方式 |
| `align` | `"right" \| "left" \| "between" \| "center"` | 否 | 水平对齐方式 |
