# number

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"number"` | 是 | 指定为数字展示类型 |
| `precision` | `number` | 否 | 精度，用来控制小数点位数 |
| `prefix` | `string` | 否 | 前缀 |
| `suffix` | `string` | 否 | 后缀 |
| `kilobitSeparator` | `boolean` | 否 | 是否千分分隔 |
| `percent` | `number \| boolean` | 否 | 百分比显示 |
| `placeholder` | `string` | 否 | 占位符 |
| `unitOptions` | `any` | 否 | 单位列表 |
