# anchornav

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"anchor-nav"` | 是 | 指定为 AnchorNav 锚点导航渲染器 |
| `links` | `AnchorNavSectionSchema[]` | 是 | 楼层集合 |
| `active` | `string \| number` | 否 | 被激活（定位）的楼层 |
| `className` | `SchemaClassName` | 否 | 样式名 |
| `linkClassName` | `SchemaClassName` | 否 | 导航样式名 |
| `sectionClassName` | `SchemaClassName` | 否 | 楼层样式名 |
| `direction` | `"vertical" \| "horizontal"` | 否 |  |
