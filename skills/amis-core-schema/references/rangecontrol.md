# rangecontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"input-range"` | 是 |  |
| `value` | `Value` | 否 | 滑块值 |
| `max` | `string \| number` | 否 | 最大值 |
| `min` | `string \| number` | 否 | 最小值 |
| `step` | `string \| number` | 否 | 步长 |
| `unit` | `string` | 否 | 单位 |
| `showSteps` | `boolean` | 否 | 是否展示步长 |
| `parts` | `number \| number[]` | 否 | 分割块数 |
| `marks` | `MarksType` | 否 | 刻度 |
| `tooltipVisible` | `boolean` | 否 | 是否展示标签 |
| `tooltipPlacement` | `TooltipPosType` | 否 | 标签方向 |
| `multiple` | `boolean` | 否 | 是否为双滑块 |
| `joinValues` | `boolean` | 否 | 是否通过分隔符连接 |
| `delimiter` | `string` | 否 | 分隔符 |
| `showInput` | `boolean` | 否 | 是否展示输入框 |
| `disabled` | `boolean` | 否 | 是否禁用 |
| `clearable` | `boolean` | 否 | 输入框是否可清除 |
