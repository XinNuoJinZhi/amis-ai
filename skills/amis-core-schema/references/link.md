# link

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"link"` | 是 | 指定为 link 链接展示控件 |
| `blank` | `boolean` | 否 | 是否新窗口打开。 |
| `href` | `string` | 否 | 链接地址 |
| `body` | `string` | 否 | 链接内容，如果不配置将显示链接地址。 |
| `badge` | `BadgeObject` | 否 | 角标 |
| `htmlTarget` | `string` | 否 | a标签原生target属性 |
| `icon` | `string` | 否 | 图标 |
| `rightIcon` | `string` | 否 | 右侧图标 |
