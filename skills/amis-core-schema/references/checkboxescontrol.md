# checkboxescontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"checkboxes"` | 是 |  |
| `checkAll` | `boolean` | 否 | 是否开启全选功能 |
| `defaultCheckAll` | `boolean` | 否 | 是否默认全选 |
| `checkAllText` | `string` | 否 | 全选/不选文案 |
| `columnsCount` | `number \| number[]` | 否 | 每行显示多少个 |
| `menuTpl` | `string` | 否 | 自定义选项展示 |
