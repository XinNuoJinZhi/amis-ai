# spinner

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"spinner"` | 是 | 组件类型 |
| `show` | `boolean` | 是 | 控制Spinner显示与隐藏 |
| `className` | `string` | 否 | 自定义spinner的class |
| `spinnerClassName` | `string` | 否 | spin图标位置包裹元素的自定义class |
| `spinnerWrapClassName` | `string` | 否 | 作为容器使用时最外层元素的class |
| `mode` | `string` | 否 |  |
| `size` | `"" \| "sm" \| "lg"` | 否 | spinner Icon 大小 |
| `icon` | `string` | 否 | 自定义icon |
| `tip` | `string` | 否 | spinner文案 |
| `tipPlacement` | `"top" \| "right" \| "bottom" \| "left"` | 否 | spinner文案位置 |
| `delay` | `number` | 否 | 延迟显示 |
| `overlay` | `boolean` | 否 | 是否显示遮罩层 |
| `body` | `SchemaCollection` | 否 | 作为容器使用时内容 |
