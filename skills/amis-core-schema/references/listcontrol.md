# listcontrol

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `type` | `"list-select"` | 是 |  |
| `submitOnDBClick` | `boolean` | 否 | 开启双击点选并提交。 |
| `imageClassName` | `string` | 否 | 图片div类名 |
| `itemSchema` | `SchemaCollection` | 否 | 可以自定义展示模板。 |
| `activeItemSchema` | `SchemaCollection` | 否 | 激活态自定义展示模板。 |
| `listClassName` | `SchemaClassName` | 否 | 支持配置 list div 的 css 类名。<br>比如：flex justify-between |
