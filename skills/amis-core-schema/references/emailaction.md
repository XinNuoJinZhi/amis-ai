# emailaction

| 属性 | 类型 | 必选 | 说明 |
|---|---|---|---|
| `actionType` | `"email"` | 是 | 指定为打开邮箱行为 |
| `to` | `string` | 是 | 收件人邮箱 |
| `cc` | `string` | 否 | 抄送邮箱 |
| `bcc` | `string` | 否 | 匿名抄送邮箱 |
| `subject` | `string` | 否 | 邮件主题 |
| `body` | `string` | 否 | 邮件正文 |
