# 图片展示（type: `image`）

> 可以用来展示一张图片，支持静态设置图片地址，也可以配置 <code>name</code> 与变量关联。

**标签**：展示
**编辑器面板**：图片
**图标**：`fa fa-photo`
**文档**：`/amis/zh-CN/components/image`
**基础组件**（编辑器内可直接拖拽）

## 默认 scaffold（建议起手用法）

```json
{
  "type": "image"
}
```

## 事件

| eventName | eventLabel |
|---|---|
| `click` | 点击 |
| `mouseenter` | 鼠标移入 |
| `mouseleave` | 鼠标移出 |
