## 异常观察

### 1. `__null__` 占比 47.6%（122/256）— **大幅下降前置已修**

- baseline 5-13 evening 是 54%，本周降到 47.6%。
- **真因今天定位**（详见 fa459a4 commit）：backend restart 后 agent FastAPI 冷启动窗口 3-30s，第一波业务任务 5s timeout 触发 → 落 (None, None) → 写 NULL。
- **fix 已上线**（fa459a4）：start-services.sh 加 `wait_for_health` 在 agent / backend 都返回正确 service 字段后才退出。
- **预计 W4 末**：next 7d NULL 占比降到 < 10%（只有真正 LLM 错误才会 NULL，不再是冷启动）。

### 2. `__null__` est/actual ratio = 19.85 🚨

- 不是新 bug，是历史包袱：1.5 W2 调到 200/140 校准之前的老任务 estimate 用了原始粗估公式（5k-10k 量级），actual 真实 200k-400k → ratio 暴涨。
- 新任务（5-12 后）走 estimate_task_cost_calibrated → ratio 趋向 1.0。
- 30d 窗口滚动到 6-12 后，老任务退出窗口，ratio 自然回归。

### 3. 所有 named category ratio 在 [0.54, 0.93]

- 系数 140 偏保守（高估 7-46%），但**不会预算超支**，对用户友好。
- 想更精准可调到 **180**：
  - oa_form: 0.93 × 180/140 = 1.20（轻微超估，可接受）
  - admin_settings/static_page: 0.54-0.55 × 180/140 = 0.70-0.71（仍保守 30%）
- **决策**：暂保持 140，等 6 月再积累一周数据看 ratio 是否仍稳定。

### 4. page_quality_verdict last_7d 全 0（未活动）

- W1 A 项 page-bad 自动入库总闸（`rag.judge.auto_page_negative`）仍关闭。
- 累计 verdict：35 needs_review / 7 bad / 4 good（全部 5-13 前的）。
- 已有 1 个自动入库样本（status=pending_review）— 1.6 W1 实证留下。

### 5. ab_variant 100% null

- W3 A/B 总闸（`llm.routing.ab_test_enabled`）仍关闭，符合预期。
