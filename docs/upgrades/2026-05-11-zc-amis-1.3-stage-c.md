- **路径**：[shared/docker/sandbox/zc-web-node20/](../../shared/docker/sandbox/zc-web-node20/)

- **路径**：[scaffolds/zc-editor-web-template/](../../scaffolds/zc-editor-web-template/)

- 新增 `image: Option<String>` 字段（向后兼容；None 走 sandbox-service 启动默认）
- 注册 `zc-editor-web-template` 条目：`platform=web, tech_stacks=[react], ui_libs=[antd, zc-amis], image=amis-ai-sandbox:zc-web-node20, dev_command=pnpm run vite:dev, default_skill_buckets=[_common, platform-zc-web, stack-react, ui-antd, zc-amis-schema]`

### 4. sandbox-service 多镜像路由改造

- `sandbox/src/docker.rs` `CreateOpts` 加 `image: Option<&str>` —— per-create override，None 走 DockerClient 默认
- `sandbox/src/handlers.rs` `CreateSandboxRequest` 加 `image: Option<String>`
- `backend/src/services/sandbox_client.rs` `create_with` signature 改成 `(task_id, dev_command, image)`，CreateSandboxRequest 透传 image
- `backend/src/handlers/project_generation.rs` 按 `template_registry.image` 下发，无侵入 / 向后兼容

## 二、关键决策

| 决策点 | 拍板 | 原因 |
|---|---|---|
| ZC nexus 包源接入方式 | **公网 URL 直装** + 离线 .tgz fallback | 实测 `app.xinnuojinzhi.com:8081` 公网可达，最简方案 |
| sandbox-service 多镜像处理 | per-create image override（进程不变） | 比"每模板起一个 sandbox-service"轻量得多 |
| zc_editor 精简程度 | 14MB（保留 codegen 核心 + engine + 模式参考页） | 远低于设计稿 30MB 上限；脱离 ZC 后端时 dev server 仍可启动 |
| Locale 保留范围 | 仅 zh-CN + en-US（剥 6 个语种） | codegen 用不到非主流语种，省 ~250KB |

### 阶段 C.5 修坑记录

第一次 install 中途 fail 于 `git+ssh://github.com/xqq/webworkify-webpack.git` —— ZC fork amis-6.8.0-my324v2 的 deep dep 含一个 git+ssh:// 形式 URL，Alpine 镜像无 ssh client 且无 GitHub key。`zc_editor` 的 `package.json overrides.webworkify-webpack` 没生效（pnpm 9 对 deep git URL 不应用 overrides）。

**修复**：Dockerfile 加系统级 git url.insteadOf 把 `git+ssh:// / ssh:// / git@github.com:` 全部透明改 `https://github.com/`，rebuild 后 install 顺畅过关。
