## 一、超预期发现

设计稿原本预估 1.3.1 工作量 **3-5 天**，实际**一次 session 干完**——核心原因：

**zc_uniapp 不依赖 ZC 私有 nexus**。源码 272MB 大头是 node_modules 263MB，去除后只剩 9MB；package.json 17 个 dependencies 全部走公共 npm（@dcloudio + wot-design-uni），完全可以**复用 1.2 的 `amis-ai-sandbox:uniapp-node20` 镜像**，零新增镜像、零网络改造。

这跟 1.3.0 阶段 C 造 zc-web-node20 镜像 + 修 git insteadOf 那种重投入完全不同。
