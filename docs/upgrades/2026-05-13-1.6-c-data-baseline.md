## 快照采集步骤

### 1. 当前 task 计数（按 category × tier）

```sql
SELECT
  COALESCE(category, '__null__') AS category,
  COALESCE(complexity_score::int::text, '__null__') AS score_int,
  COUNT(*) AS task_count,
  COUNT(*) FILTER (WHERE status = 'succeeded')                 AS succeeded,
  COUNT(*) FILTER (WHERE status = 'failed')                    AS failed,
  COUNT(*) FILTER (WHERE actual_cost_tokens IS NOT NULL)       AS has_actual_cost,
  COUNT(*) FILTER (WHERE accumulated_cost_tokens IS NOT NULL)  AS has_accum_cost
FROM project_generation_task
WHERE created_at >= NOW() - INTERVAL '30 days'
GROUP BY 1, 2
ORDER BY task_count DESC;
```

### 2. actual_cost_tokens 分布（per category）

```sql
SELECT
  COALESCE(category, '__null__') AS category,
  PERCENTILE_CONT(0.5)  WITHIN GROUP (ORDER BY actual_cost_tokens) AS p50,
  PERCENTILE_CONT(0.9)  WITHIN GROUP (ORDER BY actual_cost_tokens) AS p90,
  PERCENTILE_CONT(0.99) WITHIN GROUP (ORDER BY actual_cost_tokens) AS p99,
  AVG(actual_cost_tokens)::int AS avg_cost,
  COUNT(*) AS n
FROM project_generation_task
WHERE actual_cost_tokens IS NOT NULL
  AND status = 'succeeded'
  AND created_at >= NOW() - INTERVAL '30 days'
GROUP BY 1
ORDER BY n DESC;
```

### 3. estimate vs actual 误差（W2 校准用）

```sql
SELECT
  COALESCE(category, '__null__') AS category,
  AVG(estimated_cost_tokens) AS avg_est,
  AVG(actual_cost_tokens)    AS avg_act,
  AVG(actual_cost_tokens::float / NULLIF(estimated_cost_tokens, 0))::numeric(10,2) AS act_div_est_ratio,
  COUNT(*) AS n
FROM project_generation_task
WHERE estimated_cost_tokens IS NOT NULL
  AND actual_cost_tokens IS NOT NULL
  AND status = 'succeeded'
  AND created_at >= NOW() - INTERVAL '30 days'
GROUP BY 1
HAVING COUNT(*) >= 10
ORDER BY n DESC;
```

> 当前 W2 校准系数固定为 200（1.5 W2 单点实测推断）。如果某 category 的 `act_div_est_ratio` 远偏离 200，则需要单独配 `llm.quota.estimate_calibration_factor_{category}` 覆盖。

### 4. ab_variant 分布（W3 A/B 用，目前应几乎全 null）

```sql
SELECT
  COALESCE(ab_variant, '__null__') AS variant,
  COUNT(*) AS task_count,
  COUNT(*) FILTER (WHERE status = 'succeeded') AS succeeded,
  AVG(actual_cost_tokens)::int AS avg_cost
FROM project_generation_task
WHERE created_at >= NOW() - INTERVAL '30 days'
GROUP BY 1
ORDER BY task_count DESC;
```

### 5. page-bad 触发情况（1.6 W1 A 项接通后才有意义）

```sql
SELECT
  page_quality_verdict,
  COUNT(*) AS n,
  COUNT(*) FILTER (WHERE created_at >= NOW() - INTERVAL '7 days') AS last_7d,
  MIN(page_quality_judge_at) AS first_at,
  MAX(page_quality_judge_at) AS last_at
FROM project_task_page
WHERE page_quality_verdict IS NOT NULL
GROUP BY 1
ORDER BY n DESC;

-- A 项自动入库到 code_samples 的行
SELECT status, COUNT(*) AS n
FROM code_samples
WHERE source_page_id IS NOT NULL
GROUP BY status;
```
